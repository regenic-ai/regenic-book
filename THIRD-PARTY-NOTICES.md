# Third-Party Notices

Regenic includes third-party software distributed under its own license
terms. The authoritative dependency set and resolved versions are recorded in
`package.json` and `package-lock.json`.

Copyright notices and license texts for installed npm packages are available
in each package's metadata and distribution. Those terms apply independently
of Regenic's MIT and CC BY-NC 4.0 licenses.

Before each public release, maintainers should:

1. install from the lockfile with `npm ci`;
2. review production and development dependency licenses;
3. preserve required copyright and attribution notices;
4. document any bundled non-code assets and their provenance here; and
5. stop the release if a dependency's terms are unknown or incompatible.

No third-party manuscript, image, dataset, font, logo, or other asset is
declared for redistribution by this notice. Such material must carry a
specific source and license entry before inclusion in a release.

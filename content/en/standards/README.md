# Public Regenic standards

Regenic turns tacit judgment into a shared standard that people and AI can
understand, apply, check, and revise.

Every publishable standard should state five things:

1. **Applicability** — when to use the standard.
2. **Action** — the decision or behavior expected from a person or AI.
3. **Acceptance evidence** — what observable result shows that the action worked.
4. **Stop or escalation condition** — when the standard must no longer be followed
   as written and the work must stop or move to a higher judgment.
5. **Revision trigger** — what new evidence requires the standard to change.

Public contributions must not include personal data, client-confidential
information, private financial data, or claims that cannot be sourced.

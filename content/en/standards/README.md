# Public Regenic standards

Regenic standards turn tacit judgment into an artifact that people and AI can
apply, test, and revise.

Every publishable standard should state:

1. **Condition** — when the standard applies.
2. **Action** — the expected decision or behavior.
3. **Acceptance** — observable evidence that the action worked.
4. **Boundary** — when the standard must stop or escalate.
5. **Revision trigger** — evidence that requires the standard to change.

Public contributions must not include personal data, client-confidential
information, private financial data, or claims that cannot be sourced.

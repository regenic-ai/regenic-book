# 前言　最后的稀缺

状态：完稿（v2.0，2026-09-20）

**论断：在数字化知识工作中，AI 正在同时压低执行和获取已有知识的成本；当“做出来”和“查出来”越来越便宜，悟性便成为最后的稀缺，而 AI 原生组织的任务，是把它沉淀为共同的标准与上下文。**

---

## 一、两种成本一起往下走

Epoch AI 把不同模型放到同一条能力门槛上比较。在 MMLU 通识知识基准中，GPT-4-0314 于 2023 年 3 月取得 86 分，当时的加权 API 价格是每百万 token 约 37.5 美元。到 2025 年 2 月，Gemini 2.0 Flash 以 88 分越过同一门槛，价格降到约 0.18 美元。约二十三个月，达到这条固定能力线的价格变成了原来的约二百分之一（Epoch AI，2025）。

这组数字有明确边界。Epoch AI 按输入和输出 token 的价格以 3∶1 加权，也没有把会大量生成中间 token 的推理模型纳入逐 token 比较。它衡量的是达到固定基准能力的 API 价格，不是企业完成一项工作的总成本。接入、核验、返工和承担结果的责任，都不在其中。

即便如此，这条曲线仍在改变数字化知识工作的底价。只要输入和输出是数字信息，质量也能在数字世界里验收，原来按人工工时购买的许多步骤，就可以交给模型先做。代码初稿、资料整理、文档摘要、报告结构和翻译初稿，都属于这一类。机器调用没有把整项工作的成本打到零，却在压低其中可重复执行的部分。

同一项能力也在缩短人找到已有知识的路径。过去要先检索、筛选、通读再摘要的材料，现在可以由 AI 先做整理，人再回到原始来源核验。便宜的是寻找和初步加工信息的摩擦，不是事实自动变真，更不是专业知识已经被理解、验证和迁移。

当“做出来”和“查出来”一起变便宜，建立在熟练执行和信息差上的优势就会变薄。低价的模型调用并不会替组织确定什么问题值得解决、眼前该采用哪一把尺子、现有材料是否足以支持行动。由此暴露出来的那项稀缺，我称为**最后的稀缺**。

## 二、“最后”不等于其他稀缺消失

执行没有归零。AI 不能把施工、护理和最后一公里配送变成一次模型调用；审计、合规和牌照也不会因为 token 降价而自动取消。即使在数字世界里，人仍要付出接入、核验、返工和担责的成本。本书所说的“归零”，描述的是数字化知识工作中边际执行价格迅速下行的方向。它不是数学上的零，也不是所有行业会在同一天抵达同一个终点。

算力和能源也没有停止稀缺。芯片、供电、机房和接入条件都可能成为瓶颈，不同组织获得它们的价格与难度也不相同。区别在于，算力和能源有明确的价格与供给约束，可以进入预算、采购和资源配置。资本能缓解其中一部分瓶颈，却不能回答它们是否值得买、该用在哪里、什么时候应该停止投入。

组织当然也可以雇人才、请顾问、并购能力，从外部借来答案和经验。但是，采购不能替眼前的组织确认适用条件，也不能替责任人承担结果。模型、算力和外部经验都可以成为判断的材料，不能自动成为这个组织的判断。

因此，“最后”不是说它是宇宙中最后一种稀缺，也不是对算力和能源价值的否认。它说的是本书讨论的组织竞争：当执行和获取已有知识不再是主要门槛，能否在新问题面前形成可靠判断，会成为更难复制的差距。

## 三、四个词，一条线

这本书会反复使用四个词。它们指向同一件事在不同层次上的形态，却不能随意互换。**最后的稀缺**是这件事的名字。**悟性**是它在个人身上的能力。**判断力**是它在组织里的资产。**标准**是判断被写下来、供人和 AI 复用的形式。

悟性并不神秘。它表现为四个连续动作。先发现当前判断缺少什么标准，再从已经验证过的人和组织那里借来标准及其适用条件，然后判断它能不能迁到眼前的问题，最后用低成本试验验证，并根据结果修正。

一个人完成这四个动作，得到的是个人悟性。个人判断只有被组织共同使用，才可能成为组织的判断力。判断被写下来，才有了可检查、可复用的标准形式。《重写基因》关心的不只是一个人怎样变敏锐，而是组织怎样把悟性沉淀为共同的判断标准和共同的上下文。个人悟性很难靠复制个人来放大，组织却必须让这种能力离开个别人的头脑，成为可以共同使用的资产。

## 四、从裂缝到基因进化

全书十四章，分成四部，顺序对应一次组织进化的过程。

**第一部“大过剩”（第 1—2 章）**先寻找裂缝。执行和获取已有知识的成本究竟降到了什么程度，适用范围在哪里？为什么工具越来越多，多数组织却没有因此变强？这里先确认旧世界的哪些前提正在失效。

**第二部“最后的稀缺”（第 3—5 章）**拆开那项没有随工具一起交付的能力。它在个人身上怎样运转，在组织里怎样成为资产，又为什么会成为 AI 原生组织需要经营的限制性资源。

**第三部“稀缺的生产”（第 6—9 章）**讨论组织怎样把它生产出来。从标准循环开始，经过清晰术与干扰术，再进入全公司的共识循环。同一套判断由此从一个人走向一个团队，再走向整个组织。

**第四部“基因进化”（第 10—14 章）**把这套能力放进五个战场：人、时间、产品、关系和组织。最后一章用九十天完成第一轮替换，让新的判断方式真正进入日常工作。

书中会区分事实与主张。外部数字标明出处；公司口径和未经审计的数据说明成色；证据缺少一侧时保留缺口，不用一个漂亮故事冒充规律。每章最终都要把判断落成读者可以在周一开始的动作。书是当前这一版完整论述，Regenic.ai 持续公开修订，bioby.ai 是第一个实验场。

你不必先接受后面所有结论。更合适的读法，是把每一章都当作一项可以被反驳的判断：先看证据，再看边界，最后拿自己的组织验证。

## 五、从两个问题开始

开始之前，先问自己的组织两个问题：

1. **如果数字化知识工作的执行和获取已有知识的成本继续下降，公司今天最值钱的东西，还有多少会在明天保持价值？**
2. **遇到一个从未做过的问题时，我们能否发现缺少什么标准，借来已经验证过的标准，判断它能否迁移，再用小成本试验完成修正？**

第一问答不上来，说明组织的优势可能还压在正在变便宜的执行和信息差上。第二问答不上来，说明组织还在依赖少数能人临场发挥：人一换，过去交过的学费就要重新再交。

这两个问题不要求你相信 AI 能做一切。恰恰相反，它们要求我们先分清哪些东西正在变便宜，哪些责任仍必须由人承担。所有后文都可以从反驳开始。第 1 章先回答最直接的一问：**执行真的会归零吗？**

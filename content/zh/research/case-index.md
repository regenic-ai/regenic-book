# 公开案例索引

> 公开版索引：只收录**外部可核验**案例与章节映射。完整案例库（含内部 I 系列卡片、口述素材与待补数据）存放于私有研究库，不进入公开仓库。

## 收录原则

- 全书目标 10–15 组关键对照；核心论断必须同时有赢家与输家样本。
- 任何一侧缺失都要显式标记，补齐前不得用单侧故事提炼普遍标准。
- 赢家与输家分别统计**中位数**，不混成平均数。
- 内部实验案例可以支撑叙述，但**不能是唯一证据**。

## 双侧样本原则

- 赢家与输家的收集优先级相同。
- 先冻结「赢/输」的结果定义，再找样本。
- 对照尽量匹配行业、组织阶段、资源约束和时间窗口。
- 无法配对时，结论降级为待验证假设。

## 贡献方式

1. 在 GitHub Issues 提出案例线索，注明来源与章节归属。
2. 公开 PR 只提交**已脱敏、可引用来源**的材料。
3. 内部经营数据、客户名与未审计数字请通过维护者私下通道提交，不要进入公开 PR。

完整卡片、对照组细节与核实记录不在公开仓库发布。

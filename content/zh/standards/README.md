# Regenic 公开标准

Regenic 的目标，是把隐性的判断写成一套人和 AI 都能理解、执行、检查和修订的共同标准。

每条可公开的标准都应说明五件事：

1. **适用条件**：在什么情况下使用。
2. **动作**：希望人或 AI 作出什么判断、采取什么行为。
3. **验收证据**：看到什么，才能说明动作有效。
4. **停止或升级条件**：什么情况下不能继续照做，必须停下或交给更高层判断。
5. **修订触发器**：出现什么新证据时，必须修改这条标准。

公开贡献不得包含个人数据、客户机密、内部财务数据或无法注明来源的事实主张。

公开标准索引见 `/zh/standards` 与 `/en/standards`。

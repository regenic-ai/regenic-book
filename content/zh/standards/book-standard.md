# 本书公开标准

> 公开版标准：供贡献者与读者理解 Regenic 方法的结构与验收口径。完整编辑决策记录与变更流水不进入公开仓库。

## 一、产品标准：管理学畅销书五件套

取《跨越鸿沟》《创新者的窘境》《从优秀到卓越》《精益创业》《从0到1》《蓝海战略》等样本的中位数特征：

1. **一个反直觉的核心论断**——一句话，可证伪。
2. **一个可复用的主框架**——读者能拿走一张图。本书：双能力模型（判断标准 + 上下文）。
3. **3-5 个命名概念**——一级概念 ≤5 个，其中「重写基因 / Regenic」为唯一主推；完整分级见 `outline.md`。
4. **案例支撑论断**——核心论断同时收集赢家与输家样本；每章至少 1 组外部对照或明确说明缺失侧。
5. **一套可执行 playbook**——读者周一上班就能用。本书：第 13 章 90 天手册。

**主读者**：一号位（创始人 / CEO / 事业部负责人）。

**载体关系**：《重写基因》是方法论当前的公开完整论述；Regenic.ai 是持续更新的载体；bioby.ai 是第一个内部实验场与装配样本，不作为方法论官网。

**服务边界**：Regenic 帮助企业识别限制性资源、提炼标准、冻结验收口径、组织第一轮验证；不替一号位判断，不代写脱离现场的标准，不承诺把转型外包。

## 二、公开命名标准

- 主书名：**《重写基因》/ Regenic**
- 副标题：**如何构建 AI 原生组织 / How to Build an AI-Native Organization**
- 「最后的稀缺」保留为一级概念与潜在续作标题，不作为主书名。

书名评分与市场测试细节属于内部编辑资料，不在公开仓库维护。

## 三、章节验收标准

每章完稿必须同时满足：

1. 论断可用一句话复述，且与全书核心论断构成推论关系。
2. 有一张可以画在白板上的框架图。
3. 至少 1 组赢家/输家外部对照 + 可引用的数据；统计分别报告两侧的**中位数**。
4. 至少 3 句金句候选。
5. 结尾有「周一早上怎么做」的动作清单。
6. 正文段落通过 [`prose-standard.md`](./prose-standard.md) 畅读验收（四戒、旁白/硬隐喻、文内作者—年份引用）。

## 四、写作流程标准（10/10/80）

- **10% 提炼标准**：本文件 + `outline.md` + [`prose-standard.md`](./prose-standard.md)。
- **10% 收集数据**：公开研究索引 + 私有案例库（内部案例不得作为唯一证据）。
- **80% 以手段求优解**：每章先写一页纸 → 跑通逻辑闭环 → 逐章展开 → 按畅读标准清旁白与硬接。

章节状态机：`一页纸 → 展开中 → 完稿 → 持续公开修订`。

## 五、公开成功验收

长期验收：核心概念是否成为组织语言；有多少团队用书里的标准完成第一轮改造；Regenic.ai 是否持续公开可复测的成功、失败与边界案例。
